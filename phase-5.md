# Phase 5: Advanced Topics & Real-World Applications

The final phase covers the more advanced, industry-relevant areas of the blockchain domain and pulls everything together into full-stack, real-world project building.

## Topics List

### 5.1 Decentralized Finance (DeFi)
- Core DeFi Primitives: DEXs, Lending, Borrowing, Yield Farming
- Automated Market Makers (AMMs) and Liquidity Pools
- Lending Protocols: Collateralization and Liquidation Mechanics
- Stablecoins: Fiat-Backed, Crypto-Backed, and Algorithmic
- Risks in DeFi: Impermanent Loss, Smart Contract Risk, Flash Loan Attacks

### 5.2 DAOs & Governance
- What is a Decentralized Autonomous Organization?
- On-Chain Governance and Voting Mechanisms
- Governance Tokens and Delegation
- Treasury Management and Multi-Signature Wallets

### 5.3 Cross-Chain Interoperability
- Why Cross-Chain Communication Matters
- Bridges: Lock-and-Mint vs. Liquidity Pool Models
- Bridge Security Risks and Notable Exploits
- Interoperability Protocols (LayerZero, Wormhole, IBC)

### 5.4 Zero-Knowledge Proofs
- What is a Zero-Knowledge Proof? (Conceptual Overview)
- zk-SNARKs vs. zk-STARKs
- Use Cases: Privacy, Scaling (zk-Rollups), Identity Verification

### 5.5 Full-Stack Project Architecture & Deployment
- Structuring a Full-Stack Project (Frontend, Smart Contracts, Scripts)
- Connecting a React Frontend to a Hardhat/Foundry Project
- Planning and Designing a Real Application
- Deploying Smart Contracts and Frontends (Vercel, Firebase Hosting)
- Post-Launch: Monitoring, Upgrades, and Audits

## Practice Exercises

**Beginner**
- Interact with a live DeFi protocol on a testnet (e.g., swap tokens on a testnet DEX or supply assets to a testnet lending pool).
- Create a proposal and vote on a test DAO using Snapshot.

**Intermediate**
- Build a simple staking contract where users can deposit a token and earn rewards over time.
- Research and diagram how a specific bridge (e.g., a lock-and-mint bridge) moves assets between two chains.

**Advanced (Capstone Projects)**
- Decentralized Autonomous Organization (DAO): Build a dApp that allows members to create proposals and vote to govern a shared treasury.
- DeFi Lending Protocol: Build a protocol where users can deposit assets to earn interest or borrow against collateral.
- Cross-Chain NFT Bridge (stretch project): Explore moving an NFT's representation between two testnets using a bridge pattern.
- On-Chain Game: Build a simple game where state and logic are managed by smart contracts.
